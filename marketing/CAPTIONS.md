## LinkedIn / longer post

> I got tired of scrubbing past the same 90 seconds in every video — "and today's video is sponsored by…" — so I built a Chrome extension that does it for me.
>
> **AutoSkip for YouTube** handles the parts you'd skip anyway:
>
> → **Sponsor reads** skip automatically, using the community-built SponsorBlock database. Works without Premium.
> → **Skippable ads** disappear the moment the countdown ends — no reaching for the button.
> → **Jump Ahead** (YouTube Premium) becomes automatic, instead of a button that only shows up when the controls do.
>
> The rule I built it around: a wrong skip should cost nothing. Every skip says what it skipped and comes with a one-tap Undo.
>
> It's also private by design — lookups never reveal which video you're watching, and there's no tracking and no account. If you want, you can plug in your own AI (a local model or your own API key) to catch sponsor reads nobody has tagged yet.
>
> Free on the Chrome Web Store: [link]
>
> Would love to hear what it gets right — and especially what it gets wrong.

## Chrome Web Store note

The store's **promo video** field only accepts a YouTube link — it won't take an
uploaded file. Upload `autoskip-promo.mp4` to YouTube (unlisted is fine) and
paste that URL into the listing.
